## Image file naming

Each image is saved as:

    images/<post_id>_<slug>.webp

where

* `post_id` is the numeric ID used in the on-site URL
  `https://gamepadla.com/upload/post/<post_id>/image-<slug>-<timestamp>.webp`
* `slug` is the URL slug of the controller (e.g. `machenike-f1-black`)

So the example URL

    https://gamepadla.com/upload/post/274/image-machenike-f1-black-1789206792.webp

is saved locally as

    images/274_machenike-f1-black.webp

The local filename **drops the trailing timestamp** because that timestamp
is the site's upload time and isn't useful for the consumer of the archive.
The original timestamped URL is preserved inside `controllers.json` under
the `image_url` field of each controller.

## How the scraper works

1. **Catalog pass** — fetch `https://gamepadla.com/` and walk every catalog card.
   Each card yields `post_id`, `slug`, `name`, `brand`, `image_url`,
   button/stick latency per connection type, and tags.
2. **Detail pass** (optional, default ON) — fetch each per-controller page
   `<slug>.html` to enrich the record with LatScore grades, per-test
   min/avg/max/jitter, platforms, interfaces, contributors, etc.
3. **Image pass** — download every `image_url` to `images/<post_id>_<slug>.webp`.

All HTTP requests use a desktop User-Agent and a 0.4s sleep between requests
to be polite. Cloudflare challenges are NOT bypassed — if the site challenges,
the script will fail loudly for that URL and record the error in the manifest.

## Re-running

    python3 /home/z/my-project/scripts/gamepadla_scraper.py

Useful flags:

    --no-details        # skip the slower detail-page pass
    --no-images         # skip image downloads
    --limit 10          # only scrape first 10 controllers (testing)
    --sleep 0.8         # sleep longer between requests
